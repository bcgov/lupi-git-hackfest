# Hackathon Instructions: Collaborative AI Novel Creation with GitHub

Welcome to the GitHub Hackathon!  
This event is designed to help you learn GitHub by collaborating on a creative AI-driven novel, with each team contributing a unique chapter composed of AI-generated text and images.

---

## Overview

- **Goal:** Learn GitHub by collaboratively writing a novel using AI-generated prompts (text and images).
- **Structure:** Each team is assigned a chapter. Team members work individually on their contributions, then merge them into their chapter branch before submitting the chapter to the main repository.

---

## Step-by-Step Instructions

### 1. Get Started

- Access the GitHub repository for the hackathon.
- Choose your preferred workflow: you can use the Git command line, GitHub Desktop, or Visual Studio Code (with the GitHub integration).

---

### 2. Chapter Branches

- Each team should create a branch for their assigned chapter (e.g., `chapter-3`).
- All work for your chapter will be done in this branch.

---

### 3. Personal Contribution Branches

- Each team member creates their own branch from the team chapter branch (e.g., `chapter-3-alex`).
- Use your branch to add your AI-generated text and/or images for the chapter.

---

### 4. Submit and Sync Your Work

- When ready, merge your personal branch into your team's chapter branch.  
  (This can be done via a Pull Request or merge, depending on your workflow.)
- Please delete your personal branch after it’s merged.

---

### 5. Finalize and Submit the Chapter

- Once all team contributions are merged into the team chapter branch and the chapter is complete:
    - Open a Pull Request from your team’s chapter branch to the main branch of the repository.
    - Tag your team members and a mentor for review.
    - Address any feedback, then merge when approved!

---

## Tips

- **Choose Your Tools:** You may use GitHub through the command line, GitHub Desktop, or within Visual Studio Code.
- **Commit Often:** Make frequent, meaningful commits to track your progress.
- **Communicate:** Use Pull Requests and comments to collaborate and review each other's work.
- **Ask for Help:** Don’t hesitate to reach out to a mentor if you get stuck.
